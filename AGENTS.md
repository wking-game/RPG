# AGENTS.md – Kurzfassung für ChatGPT / Codex

Projekt: Open-World-Koop-Siedlungs-RPG (Wikinger/Mittelalter), Unreal Engine 5.8, Leitspiel Aska.
Vollständige Regeln stehen in `CLAUDE.md` – sie gelten für alle Agenten.

- **Deine Rolle (ChatGPT): Design.** Siehe `design/CHATGPT_BRIEFING.md`. Ergebnisse gehören nach `design/inbox/`.
- **Nicht anfassen:** `game/`, `data/`, `CLAUDE.md`, `docs/01_entscheidungen.md`. Code und Spielwerte setzt Claude Code um.
- Nur ein Agent steuert den Unreal-Editor gleichzeitig.
- Ehrlich schreiben, eigene Ergebnisse prüfen, Anfragen hinterfragen.
- Verschieben, Löschen oder Umschreiben wichtiger Dateien nur nach ausdrücklicher Bestätigung des Nutzers, jedes Mal neu.
- KI-generierte Inhalte (Bild, Audio, Text) in `design/asset_log.md` eintragen.
